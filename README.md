# ChatApp



Part 1



Java Maven console application for user registration and login.

The application includes username, password, cellphone number and login validation, with JUnit tests for the required functionality



\##Testing 



The project uses JUnit 5 for automated testing and Maven to run the test suite.



The GitHub Actions workflow automatically runs the Maven tests when changes are pushed to the main branch.



\## Features



\- User registration and validation

\- Username and password validation

\- Cellphone number validation

\- User login authentication

\- JUnit automated testing
